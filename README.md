# Lucid Lens

A Shape of Dreams companion app for Windows: a searchable codex of Memories, Essences, Travelers and star nodes; an unlock tracker; a run journal; a build planner with an Essence auditor; and an in-game HUD that shows where you are in a run.

This repository only hosts the **release builds**. It's also the update feed the app checks.

Non-commercial fan work. The installer contains no game data or images: Lucid Lens reads them from your own game install. It never writes your saves and never reads game memory.

## Download

**[⬇ Download the latest version](https://github.com/ostevennugent/lucid-lens-releases/releases/latest)**: on that page, under **Assets**, click `LucidLens-Setup-<version>.exe`.

## Install

1. Run `LucidLens-Setup-<version>.exe`.
2. Windows may show **"Windows protected your PC"** because the installer isn't code-signed. Click **More info → Run anyway**.
3. Follow the installer. If your game isn't in `D:\SteamLibrary\steamapps\common\Shape of Dreams`, set the path in **Settings**.

## Updates

Lucid Lens updates itself. It checks this page when it starts and every 6 hours, downloads new versions in the background, and asks **Restart and update** or **Later**. Later installs the update the next time you quit the app.

You can see your version and check manually in **Settings → App & updates**.

## In-game HUD

Run Shape of Dreams in **Borderless Windowed** so the HUD can appear on top of the game.

| Key | Action |
|---|---|
| `Alt+Q` | Open the main window |
| `Alt+W` | Show / hide the HUD |
| `Alt+L` | Toggle HUD click-through |
